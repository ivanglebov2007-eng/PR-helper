# Telegram PR Manager Bot

🤖 Бот для управления медиа-партнерствами в Telegram с системой форумных тем.

## 📋 Описание

Бот предназначен для взаимодействия PR менеджеров с руководством (Chief PR Manager и Dep.Chief PR Manager). PR менеджеры создают запросы на медиа-партнерство через бота, которые автоматически превращаются в темы в форум-группе.

### 🎯 Основные возможности

- ✅ Создание запросов на медиа-партнерство
- 📸 Загрузка скриншотов переписки
- 🔗 Валидация ссылок на YouTube, Twitch, TikTok
- 📋 Автоматическое создание тем в форум-группе
- 🔔 Уведомления руководства
- 🔍 Поиск тем по ключевым словам
- 👥 Ролевая модель доступа (PR, Dep.Chief, Chief)
- 🔒 Закрытие тем администраторами
